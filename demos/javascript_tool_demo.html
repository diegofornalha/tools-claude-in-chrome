🎯 JavaScript Tool - Demonstração Completa

Execução de código JavaScript em páginas web via MCP

📖 O que é JavaScript Tool?

A javascript_tool é uma ferramenta MCP (Model Context Protocol) que permite executar código JavaScript diretamente em páginas web abertas no Chrome. É uma das ferramentas mais versáteis do conjunto Claude in Chrome.

💡 Em resumo: Permite que o Claude controle e interaja com páginas web executando JavaScript arbitrário!

🔧 Tipos de Operações Disponíveis

A javascript_tool suporta diferentes tipos de operações via parâmetro action:

✅ javascript_exec (Padrão)

Executa código JavaScript arbitrário na página

{ "action": "javascript_exec", "tabId": 12345, "text": "document.title" }

Uso: Ler propriedades, manipular DOM, extrair dados, executar funções

ℹ️ Observação

A javascript_tool é especializada em JavaScript. Outras operações como navegar, clicar, ou redimensionar são feitas por tools diferentes (navigate, computer, resize_window, etc.)

💡 Dica: Para cada tipo de operação existe uma tool específica. JavaScript é só uma das many tools disponíveis no Claude in Chrome!

⚙️ Como Funciona?

📡 Fluxo:

  1. Claude recebe comando JavaScript
  2. Tool executa via Chrome DevTools Protocol
  3. Código roda no contexto da página
  4. Resultado é capturado e retornado

🔧 Tecnologias:

  • Chrome DevTools Protocol
  • Runtime.evaluate API
  • MCP Bridge para comunicação
  • Sandbox Execution segura

📋 Parâmetros

Parâmetro Tipo Descrição Obrigatório
tabId number ID da aba onde executar o código ✅ Sim
action string Ação a executar (ex: "javascript_exec") ✅ Sim
text string Código JavaScript a ser executado ✅ Sim

💡 Exemplos Práticos

1. Ler Propriedades da Página

Capturar informações da página atual

{ "action": "javascript_exec", "tabId": 12345, "text": "document.title" }

2. Manipular DOM

Alterar conteúdo de elementos

{ "action": "javascript_exec", "tabId": 12345, "text": "document.querySelector('#meu-elemento').innerHTML = 'Alterado!'" }

3. Ler Formulários

Obter valores de textarea

{ "action": "javascript_exec", "tabId": 12345, "text": "document.querySelector('textarea').value" }

4. Capturar Dados

Extrair informações complexas

{ "action": "javascript_exec", "tabId": 12345, "text": "Array.from(document.querySelectorAll('a')).map(a => a.href)" }

5. Interagir com APIs

Chamar APIs web

{ "action": "javascript_exec", "tabId": 12345, "text": "fetch('https://api.github.com/users/octocat').then(r => r.json()).then(d => d.name)" }

6. Simular Ações

Clicks e eventos

{ "action": "javascript_exec", "tabId": 12345, "text": "document.querySelector('button').click()" }

⚠️ Limitações

  • Contexto da página: Código executa no contexto da página atual
  • CORS: Respeita políticas de mesma origem
  • Sandbox: Execução em sandbox seguro
  • Timeout: Códigos que demoram muito podem timeout
  • DOM limitado: Acesso apenas ao DOM da página atual
  • Async: Códigos assíncronos retornam Promise

📝 Comando MCP

mcp__claude_in_chrome__javascript_tool tabId=12345 action=javascript_exec text=CODIGO_JAVASCRIPT
💡 Dica: O parâmetro text pode conter código multilinha. Use aspas adequadamente!
