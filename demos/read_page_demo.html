🔍 Read Page Tool - Demonstração Completa

Leitura e análise de conteúdo de páginas web via MCP

📖 O que é Read Page Tool?

A read_page é uma ferramenta MCP (Model Context Protocol) que permite ler e analisar o conteúdo de páginas web abertas no Chrome. É uma das ferramentas mais essenciais para extração de dados e análise de páginas.

💡 Em resumo: Permite que o Claude "veja" e interprete o conteúdo de páginas web, extraindo texto, elementos e estrutura!

🔍 Tipos de Leitura Disponíveis

A read_page oferece diferentes formas de ler páginas:

✅ all (Padrão)

Retorna todos os elementos da página (texto, botões, links, etc.)

🎯 interactive

Retorna somente elementos interativos (botões, inputs, links)

ℹ️ Observação

Cada elemento tem ref_id único para referência em outras tools!

⚙️ Como Funciona?

📡 Fluxo:

  1. Claude recebe comando read_page
  2. Tool analisa página via Chrome DevTools
  3. Estrutura da página é extraída
  4. Elementos são identificados e indexados
  5. Dados estruturados são retornados

🔧 Tecnologias:

  • Chrome DevTools Protocol
  • DOM Inspector API
  • Accessibility Tree
  • MCP Bridge
  • Element Indexing

📋 Parâmetros

Parâmetro Tipo Descrição Obrigatório
tabId number ID da aba para ler ✅ Sim
filter string Filtro opcional: "all" ou "interactive" ❌ Não (padrão: all)
ref_id string Ler elemento específico por ID ❌ Não
depth number Profundidade da árvore (padrão: 15) ❌ Não

💡 Exemplos Práticos

1. Ler Toda a Página

Capturar todos os elementos e texto

{ "action": "javascript_exec", "tabId": 12345, "text": "document.title" }

2. Ler Apenas Interativos

Extrair só botões, inputs, links

{ "action": "javascript_exec", "tabId": 12345, "text": "document.querySelectorAll('button')" }

3. Ler por Elemento Específico

Obter conteúdo de elemento por ID

{ "action": "javascript_exec", "tabId": 12345, "text": "document.getElementById('meu-elemento')" }

4. Ler Texto da Página

Extrair todo texto visível

{ "action": "javascript_exec", "tabId": 12345, "text": "document.body.innerText" }

5. Ler Links

Extrair todos os hyperlinks

{ "action": "javascript_exec", "tabId": 12345, "text": "Array.from(document.querySelectorAll('a')).map(a => ({text: a.innerText, href: a.href}))" }

6. Ler Metadados

Obter título, descrição, etc.

{ "action": "javascript_exec", "tabId": 12345, "text": "({title: document.title, url: window.location.href, description: document.querySelector('meta[name=\"description\"]')?.content})" }

  • Gerar documentação automática

⚠️ Limitações

  • Contexto: Só lê a página atual (não navega)
  • JavaScript: Não executa JS (só lê HTML/DOM)
  • Acesso: Elementos visíveis apenas (DOM renderizado)
  • Conteúdo dinâmico: Pode não capturar conteúdo carregado via AJAX
  • Páginas protegidas: Conteúdo bloqueado pode não estar disponível

📝 Comando MCP

mcp__claude_in_chrome__read_page tabId=12345
# Com filtro (apenas interativos) mcp__claude_in_chrome__read_page tabId=12345 filter=interactive
💡 Dica: Combine com outras tools! Use read_page para ver elementos, depois computer para clicar!
