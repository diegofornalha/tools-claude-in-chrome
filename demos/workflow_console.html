🔍 Console Debug Workflow

Captura e análise de mensagens do console JavaScript

📋 Sobre este Workflow

✓ Este workflow usa read_console_messages do MCP Real
O que este workflow faz:

• Captura todas as mensagens do console da página
• Identifica erros JavaScript (ReferenceError, TypeError, etc)
• Mostra warnings e logs importantes
• Filtra mensagens por padrões regex
• Perfeito para debug e análise de problemas
