📡 Network Monitor Workflow

Monitora requisições HTTP e chamadas de API

📋 Sobre este Workflow

✓ Este workflow usa read_network_requests do MCP Real
O que este workflow faz:

• Captura todas as requisições HTTP da página
• Monitora XHR, Fetch, documentos, imagens
• Mostra URLs, métodos (GET, POST, etc) e status
• Filtra por padrões de URL
• Perfeito para debug de APIs e performance
